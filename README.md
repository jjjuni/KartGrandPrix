# Kart Game

React + three.js(@react-three/fiber) + cannon-es 카트 게임. 물리는 메인 스레드에서 cannon-es를 직접 돌리고, 카트는 직접 만든 서스펜션·타이어 모델로 움직인다.

## 실행

```bash
npm install
npm run dev
```

## 조작

| 키 | 동작 |
| --- | --- |
| W / ↑ | 전진 |
| S / ↓ | 후진 |
| A / ←, D / → | 조향 |
| Space | 브레이크 |
| Shift + 방향키 | 드리프트 (28km/h 이상, 지면 위에서) — 뒷바퀴가 옆으로 미끄러지는 만큼 부스터 게이지 충전 |
| Shift 떼고 ↑ 다시 누르기 | 순간 부스터 (Shift를 뗀 뒤 0.2초 안에, 0.6초) — 게이지를 쓰지 않음 |
| ↑ 누른 채 Z | 부스터 (게이지가 가득 찼을 때, 최대 3초) — ↑를 떼면 바로 끝 |
| H | 조작 안내 접기/펼치기 |
| R | 가장 가까운 트랙 위로 리셋 |

- 드리프트는 감속 수단이기도 하다. 100km/h에서 2.4초 드리프트하면 방향키를 안 누를 때 약 73km/h, 같은 방향키를 누르면(더 깊게) 약 57km/h까지 줄어든다. 반대 방향키를 누르면 거의 펴지며 감속이 없다.
- 회전반경은 속도에 따라 달라진다 (100km/h에서 약 46~52m, 60km/h에서 약 20~32m). 드리프트 중 마찰은 운동마찰이라 접지 주행보다 코너 한계가 낮다.
- 게이지는 드리프트 중 뒷바퀴가 옆으로 미끄러지는 만큼 찬다(약 3.3초). 최고속도는 평소 100km/h(0→60km/h 약 2.3초), 부스터 중 130km/h.
- 입력 없이 거의 멈추면 기어가 P(주차)로 바뀌어 오르막에서도 굴러 내려가지 않는다. 계기판에 P / R / D로 표시.
- 도로(연석 포함) 밖 잔디에서는 접지력이 70%로 떨어지고 바퀴 저항이 커져 최고속도가 약 50km/h로 줄어든다.
- 벽에 부딪히면 부딪힌 세기(벽 방향 속도)에 비례해 감속하고, 벽을 긁는 동안 계속 느려진다 (95km/h에서 10°로 스치면 약 81km/h, 20°면 약 66km/h).
- 고속에서는 키를 끝까지 눌러도 타이어 한계 안쪽까지만 꺾인다(속도 감응 조향). 급코너는 브레이크(Space/S)나 드리프트로 감속해야 한다.
- 뒤집히거나 방벽 밖으로 나가면 자동으로 트랙 위에 다시 놓인다.
- 바퀴가 미끄러지면(드리프트, 급제동, 한계 코너링) 노면에 타이어 자국이 남는다.

## 트랙

- 길이 약 1,030m, 높낮이 있음 (동쪽 언덕 8m, 북서쪽 고원 4m)
- **낙타등 언덕**(s≈552m): 약 80km/h 이상으로 넘으면 정상에서 살짝 뜬다
- **테이블탑 점프대**(s≈722m, JUMP 표지판): 느리면 넘어가고, 최고속도(약 97km/h)면 약 30m를 날아 긴 착지 경사에 내려앉는다

## 튜닝

- 주행·드리프트·부스터: `physics/vehicle.ts`의 `KART` (질량, 관성, 서스펜션, 마찰계수, 드리프트 보조 등)
- 트랙 모양: `trackData.ts`의 CONTROL_POINTS (주석의 회전반경·간격 조건 참고)
- 높낮이: `trackData.ts`의 PROFILE_KEYS, CAMELBACK, JUMP

## 카트 물리 (physics/vehicle.ts)

- **차체**: 250kg (카트 + 운전자), 무게중심 지면 위 약 0.3m. 관성 모멘트·스프링·댐퍼는 질량에서 계산한다
  (`MASS`만 바꾸면 정지 시 눌림 5.5cm, 감쇠비 0.8이 유지되도록). 무게중심이 낮아서 가속·부스터 때 앞이 들리지 않는다.
- **엔진**: 출력 22kW. 구동력 = min(저속 최대 구동력, 출력 ÷ 속도) → 고속일수록 가속이 줄어드는 실제 특성. 공기저항·구름저항 포함.
- **서스펜션**: 바퀴마다 아래로 레이캐스트 → 스프링 + 댐퍼(리바운드가 더 강함, 블로오프로 힘 상한) + 범프 스톱 + 안티롤바.
- **타이어**: 슬립각에 비례하는 횡력(뒷바퀴가 더 단단 → 약한 언더스티어), 구동·제동력, 마찰원(합력 ≤ μ·하중), 하중 민감도(상한).
  **정지마찰 μs 1.5 > 운동마찰 μk 1.12**. 한계를 넘으면 슬립이 커질수록 마찰이 서서히 떨어지고(실제 타이어의 피크 이후 감소),
  크게 미끄러진 바퀴는 수요가 운동마찰 아래로 내려와야 다시 접지한다 — 드리프트가 유지되고 탈출 후 자연스럽게 회복되는 원리.
- **드리프트**: Shift를 누르면 뒷바퀴를 0.15초 잠가(사이드브레이크) 미끄러짐을 시작한다.
  Shift를 누르는 동안 뒷바퀴는 운동마찰 상태이고, 마찰력은 접지점이 미끄러지는 방향의 반대로 작용한다.
  ↑를 누르면 뒷바퀴 표면이 지면보다 빨리 돌아(휠스핀) 그 힘에 앞으로 미는 성분이 생겨 속도가 유지된다.
- **드리프트 보조**: 키보드로는 역조향을 섬세하게 할 수 없어서, 앞바퀴 각도만 자동으로 정한다
  (앞축의 진행 방향 + 목표 드리프트 각과의 차이에 따른 보정). 힘은 모두 타이어 물리로 계산한다.
- **부스터**: 바퀴가 아닌 무게중심에 작용하는 추진력·충격량 → 회전(앞들림)이 생기지 않는다.
- **속도 감응 조향**: 키를 끝까지 눌렀을 때 조향각 = 그 속도에서 타이어 한계로 돌 수 있는 반경에 맞는 각도 + 여유. 고속에서 뒤가 털리는 것 방지.
- **접촉 마찰 보정** (`physics/world.ts`): cannon-es는 접촉 마찰 상한을 μ·|g|·질량으로 잡아 '스텝당 충격량'으로 적용해서,
  그대로 두면 마찰이 1/스텝시간 배(120Hz면 120배) 강해진다. 벽에 스치기만 해도 달라붙어 급정거하고 튕겨 도는 원인이었기에
  `frictionGravity`에 스텝 시간을 곱해 설정한 μ대로 작용하게 했다.
- **공중 자세 보조**: 네 바퀴가 모두 떠 있을 때만 차체를 진행 방향으로 돌리고 수평으로 세운다 (비스듬히 착지해 튕겨 나가는 것 방지).
